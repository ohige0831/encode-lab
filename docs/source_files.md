## 特性と注意点

### 非圧縮生映像
コーデックが `rawvideo` であり、全フレームがピクセルデータそのまま格納されている。
圧縮・劣化が一切ない反面、1280×1024×3ch×15fps ≒ **472 Mbps** という巨大なビットレートになっており、2本合計で **約 44 GB** を占有している。

### ピクセルフォーマット (bgr24)
Red と Blue チャンネルの並びが通常の `rgb24` とは逆順の BGR 配列。
多くのエンコーダーが要求する `yuv420p` への変換が変換時に必要。

### フレームレート (15 fps)
一般的な映像 (24/30/60 fps) より低い。スローモーション再生やフレームレート変換を行わない場合は、そのまま 15 fps で出力するのが適切。

### 音声なし
音声ストリームが存在しない。変換時は `-an` フラグが自動的に付与される。

## 変換方針 (高互換性出力)

出力後のデータを広く再生できる形式にするためには、以下のプリセットが最適。

**推奨プリセット: `H.264 — Compatible (Discord / PowerPoint)`**

| 出力仕様 | 値 |
|----------|----|
| コンテナ | MP4 |
| 映像コーデック | H.264 (libx264 / profile:high / level 4.1) |
| ピクセルフォーマット | yuv420p |
| 音声 | なし (-an) |
| `faststart` フラグ | あり (Web 再生・プレビュー向け最適化) |
| 推定ファイルサイズ | CRF ベースのため可変 (目安: 各数百 MB 程度) |

### bgr24 → yuv420p の変換について
プリセットの `-vf scale=trunc(iw/2)*2:trunc(ih/2)*2` フィルターにより奇数解像度の丸め処理が行われる。
1280×1024 は両辺とも 2 の倍数なので実質スケール変更なし。
ffmpeg が bgr24 → yuv420p のカラースペース変換を自動で行う。
