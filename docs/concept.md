# EncodeLab Concept

## Core Idea

A personal video converter tool that starts simple and grows over time.

## Primary UX

- User drops video files or selects them manually
- User chooses a preset
- User optionally disables audio
- User starts conversion
- Advanced settings can be expanded later

## Initial Priorities

1. Simple GUI
2. Drag & Drop
3. Preset system
4. ffmpeg command builder
5. Safe output naming
6. Progress display

## Future Ideas

- CRF / bitrate manual input
- Resolution and FPS control
- Audio extraction
- Batch queue
- Thumbnail preview
- Estimated output size
- GPU encoding
- Developer mode with raw ffmpeg command editing
