# EncodeLab

A lightweight ffmpeg-based GUI video converter.

## Concept

Simple UI, powerful backend.

## Goals

- Drag & Drop video input
- Preset-based conversion
- Optional advanced settings
- Safe output without overwriting originals
- Extensible architecture for future features

## Tech Stack

- Python
- PySide6
- ffmpeg / ffprobe

## Status

In early design and prototyping stage.
